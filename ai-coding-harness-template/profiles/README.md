# profiles/ — 채워진 실물 사례

> `templates/`(빈칸 있는 템플릿)와 `setup/`(절차)만 보면 "그래서 실물은 어떻게 생겼나"가 안 보인다.
> 이 폴더는 실제 운영 환경의 **스냅샷**을 둔다 — 따라 하는 정본이 아니라 참고용 표본이다.

## 파일 규칙

- **파일명**: `profile-<식별자>-<YYYY-MM-DD>.md` — 날짜는 스냅샷 시점. 갱신하지 말고 새 날짜로 새 파일을 만든다.
- **커밋 전 익명화 필수**: 제품명·업무 도메인·사내 시스템명·호스트·계정을 일반화한다.
  자격증명은 익명화 여부와 무관하게 **절대 금지** (→ [`setup/README.md`](../setup/README.md) §자격증명 취급).
- **익명화하지 않을 거라면** 파일명을 `*.private.md` 로 — `.gitignore` 가 커밋을 막는다.
  개인 복원용 상세 스냅샷은 이쪽이 맞다. 공유 가치가 생기면 익명화해서 일반 파일로 승격.

## 스냅샷에 담을 것

날것의 설정 나열보다 **판단이 담긴 요약**이 오래 간다.

- 설정 실측값 (모델·권한 개수·계층 분담·MCP 목록) — 개수와 구조 위주
- **도입하지 않은 것과 그 이유** — "있는 척" 금지 원칙 (→ [GUIDE.md](../GUIDE.md) §6)
- 실제로 효과가 컸던 것 / 안 컸던 것
- 다음에 할 것
